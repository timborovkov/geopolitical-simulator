# Geopolitical Simulator

An initial playable Rust geopolitical strategy game for macOS, Linux and Windows, starting on **1 January 2000**. Govern one of 15 countries through its institutions, fund public services, expand energy and food supply, manage debt and survive political transitions. Other governments act through the same command rules.

This is a connected initial game slice of the research roadmap, originally defined as **341 proposed requirements across 42 ordered systems**. It does not implement the full catalogue. See the [initial-game scope](docs/initial-game.md) for implemented loops, simplifications and remaining work.

The [requirement audit](docs/development-progress.md) records **9 complete, 98 partial and 234 proposed**. Completed requirements cover clock/time controls (P01-01), deterministic tick/stream/hash contracts (P01-04), shared command validation and recorded outcomes (P01-05/P01-06), government/observer projections (P01-07), the headless runner (P01-08), save-conversion policy (P03-03), state/ledger/AI and first-divergence inspection (P03-04), and separately flagged developer commands with base-game inspection (P03-07). The overall systems and full game remain incomplete.

## Play

Install [Rust through rustup](https://rustup.rs/) and a native linker: Xcode Command Line Tools on macOS, a C compiler/linker on Linux, or Visual Studio Build Tools with Desktop development with C++ on Windows. The committed toolchain selects Rust 1.99.1, rustfmt and Clippy. Linux desktop play needs an X11/Wayland session, libxkbcommon and a Vulkan or OpenGL-capable graphics driver; the simulation and terminal game need no graphics stack.

Launch the native desktop game:

```sh
cargo run -p desktop --release --locked
```

Choose a country, select **Sandbox** or the authored **Fiscal and supply crisis**, and click **Begin**. Advance a day, inspect households and accounts, preview a policy, secure consent, fund it and watch delivery. Space pauses/plays; F5 saves, F9 loads and N advances to the next important event. F1 opens rebindable controls and interface scaling; Escape pauses and returns to the map. The interface includes a situation brief, charts, pinned country comparisons, a guide and a five-year objective. Long advances run off the UI thread, can stop at day boundaries and respect important-event pauses. Elections and leadership changes continue country play.

Play in a terminal:

```sh
cargo run -p headless --release --locked -- --interactive --country GBR --seed 2000
```

Type `help`. For example:

```text
advance 1
households
budget
preview energy 1
enact energy 1
advance 100
status
ledger
save campaign.json
replay
quit
```

Accepted commands identify their immediate Chronicle outcomes when the campaign supports event references. Use `event GBR#NUMBER` with the returned reference to inspect an outcome. A recorded proposal can still await consent and delivery.

Run a reproducible scenario without interaction (also the default `cargo run` behavior):

```sh
cargo run --release --locked -- --country CHN --seed 2000 --days 1827 --verify
```

Add `--scenario crisis` to the headless command for the authored fiscal/supply-crisis campaign.

The desktop map supports country-shape selection, zoom at the pointer, focus-on-country, keyboard panning and dated approval/needs/debt overlays. Metric legends explain colour thresholds, release coverage and dates. The **Statistics** selector shows the latest releases or each country’s last published values at a selected publication date. It changes the display while campaign time stays current; government labels and reference geography retain their existing context. Expand **Overlay reports — select a country** to inspect each published value/date/age and select a country; missing releases stay unknown. Debt percentages retain fixed opening annual GDP as their denominator. Separate **Lakes** and **Rivers** switches show 25 lake and 14 river features from pinned Natural Earth reference data; hover for source names and expand **Physical map sources** for provenance and coverage. These generalized features are independent of country selection and campaign rules. **Find lake / river** searches names, alternate labels and local source IDs, including Latin-accent variants. Choose a result or press Enter for a single match to show its layer and frame it on the map; the selected country and statistical overlay stay unchanged. Islands and interior holes are preserved in the supplied reference shapes; markers and search cover countries without shapes. Charts use actual release dates and provide hover, keyboard inspection and text values. Foreign reports expose published aggregates; private household accounts, treasury and AI traces stay within the controlled government.

**How to play → Search game reference** also finds opening party records and the loaded bookmark's active person, office and primary-currency references. Search names (including unaccented spellings), countries or stable references. Records retain source quality, dates and explicit vacancy/unknown-incumbency distinctions. Related-screen links and Back preserve inspection context; reference data stays separate from live campaign state. Enter and Clear keep keyboard ownership in the search editor.

Both clients load the same bundled content. Supply `--content path/to/pack.json` to either executable to use a validated local JSON pack. Unknown schema, broken references, invalid ranges and incompatible saves produce explicit errors.

## World and game data

The [initial content pack](data/initial-2000-sector-production.json) seeds 15 countries, 34 parties/governing bodies, eight institutional configurations and seven policy programs. The roster includes the UK, US, France, Germany, Russia, China, India, Japan, Brazil, South Africa, Saudi Arabia, Iran, Cuba, North Korea and Myanmar.

**The default starter has 29 pinned World Bank-mirror observations: population for all 15 countries and GDP for 14. North Korean GDP and other economic values, household profiles, seats, ideology profiles and political rules remain explicitly authored.** The source inspector distinguishes the two; the primary data API has not been independently reconciled. Historical identity names form a limited starter curation. Royal, military and religious governing bodies are explicitly scenario abstractions. All future decisions and successor cabinets are simulated. See [data provenance and coverage](data/README.md). The map combines Natural Earth public-domain land, generalized lake/river features and reference country outlines for the 15 starters. Their source revisions and transformations are pinned; they are not a certified 2000 sovereignty/control layer or dated water-extent observations. Administrative references are available through Divisions; historical geometry bound to simulation jurisdictions remains incomplete.

Opening GDP carries a nonnegative annual monetary unit, distinct from spendable cash; opening rates and capacities carry percentage units. Country definitions, live cohorts and public reports share typed population counts; on-disk counts remain unsigned integers. The campaign clock distinguishes absolute dates from elapsed periods. Configured procedure durations, policy previews, requested cash holds and regional grant terms use typed day spans, with explicit conversion to absolute dates; existing numeric content and save formats are preserved. Basis-point costs, fees, market indices and reported ratios also retain their units while preserving the same numeric files and calculations. Working-stock limits and reserve procurement quantities use typed multiples of baseline daily physical need. The household table keeps an overflow scrollbar visible when its columns exceed the view width.

Money is expressed in millions of constant-2000 USD-equivalent game credits. Displayed local currency codes are identity metadata; there is no currency exchange model yet. Stocks and realized daily flows are shown separately. Policy forecasts state their assumptions.

## Save, recover and replay

The optional `data/synthetic-territorial-test.json` adds rules 10 and snapshot format 11. **Institutions & parties → Change territorial settlement** offers lawful and contested reforms. Lawful loss of autonomy or tax rights needs an explicitly authored household-consent proxy and reserved local compensation.
