# Project instructions

- This is currently a documentation-only repository. Do not scaffold a game or add dependencies unless requested.
- The intended game is written in Rust for macOS, Linux and Windows, with government/country control and a default 2000 start.
- Dictatorships, single-party states, ideologies and other regime configurations are core systems, not optional expansions.
- Preserve the requested format: priority-ordered implementation requirements plus technical overview; do not add schedules or workload estimates unless asked.
- Preserve existing requirement IDs. Keep the Markdown specification, CSV requirement register and README counts consistent.
- Distinguish sourced historical facts, advertised game features, roadmap intentions and original design proposals. Preserve coverage limitations and citations.
- Preserve the existing Markdown documents and their local links.
- Follow CONTRIBUTING.md: inspect changes, run appropriate validation, review git status and diff, and verify remote state after an authorized push. Do not invent build/test commands for this documentation-only repository.
- When interacting with Cloudflare, use the cf CLI unless the project has a Wrangler configuration file.
